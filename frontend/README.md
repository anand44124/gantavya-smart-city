# 🌿 Gantavya Frontend Client (React + Vite + TypeScript)

This is the official frontend client for **Gantavya (गंतव्य) — Smart City Civic Governance Platform**.

## 🚀 Quickstart

```bash
npm install
npm run dev
```

## 🏗️ Architecture & Features
- **Modern Glassmorphism UI:** Built with fluid responsive CSS and frosted crystal styling.
- **PWA Ready:** 1-tap installation on Android & iOS with offline support.
- **Multilingual:** 8 regional Indian languages powered by `LanguageContext`.
- **GIS Integration:** Real-time satellite & street map rendering with Leaflet.
- **Gamification & Rewards:** Live Leaderboard, Certificate Modal, and digital scannable passes.
